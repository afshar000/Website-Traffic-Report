# Website-Traffic-Report

The Jupyter notebook "task 6.ipynb" conducts an exploratory data analysis (EDA) on a website traffic dataset loaded from "website_wata.csv" using Python libraries like pandas, numpy, matplotlib, and seaborn. The dataset contains 2000 rows and seven columns: Page Views, Session Duration, Bounce Rate, Traffic Source, Time on Page, Previous Visits, and Conversion Rate, with no missing values. The analysis begins with loading the data and displaying its first five rows, revealing metrics like high conversion rates (1.0 in many cases) and varied traffic sources (Organic, Social, Paid). Summary statistics show averages such as ~4.95 page views and ~0.98 conversion rate, with 1773 instances of a perfect conversion rate (1.0). The dataset's structure is verified through checks on data types, shape, and unique values, confirming five traffic sources and no nulls. A numerical subset (traffic_num) is created by dropping Traffic Source for further analysis. The notebook includes a scatterplot of Time on Page versus Bounce Rate, visualizing potential relationships between user engagement and site abandonment. Though truncated, the notebook lays a foundation for deeper analysis, potentially for predicting user conversions or optimizing website performance.
